# UI redesign plan

**Status:** implemented on branch `feat/ui-redesign` (sections 3 and 4, except as noted below); pending the in-game check listed in section 6.

- Not done: the minimap button is unchanged (it has no custom menu, and its tooltip is the standard game tooltip); the dash marker for missing items was not added (the missing state keeps the red border on the paper doll).
- Changed: the dropdown list scrolls with the wheel past 12 entries; the dungeon notice uses `Forever BiS` as its title and the existing message as its body.

This plan applies the "ember" design system approved for Nrage Assistant to Forever BiS. It is written so that an implementation agent can pick it up with no other context.

- **Source of the design:** `addon-nrage-assistant`, branch `feat/ui-redesign`, files `docs/REDESIGN_PLAN.md` (sections 1 and 1.4) and `NrageAssistant/UI/Kit/` (`Theme.lua`, `Pixel.lua`, `Icons.lua`, `Text.lua`, `Controls.lua`, `Shell.lua`). Read them before starting. A sibling checkout lives at `../addon-nrage-assistant/.claude/worktrees/agent-a095da82e985b52a3/`.
- **What we take:** the look (color tokens, typography, metrics, pixel borders, stroke icons, button/input/dropdown/card styles, banner, empty state). **What we do not take:** Nrage features (sidebar navigation, sync, roles, rosters, tabs). Forever BiS keeps its current behavior; only the frames change.
- **Licensing:** Fira Sans is SIL OFL 1.1: ship `OFL.txt` next to the fonts and credit it in the README. The stroke icons are our own (generated by Nrage's `tools/make_icons.py`) and may be copied.

## 1. Decisions

| Topic | Decision | Why |
|---|---|---|
| Kit scope | Port a **small theme layer**, not Nrage's full widget kit (pooling, layout engine, Table, Shell). | Forever BiS has no AceGUI and builds raw frames already. A themed helper layer restyles them with far less code and risk. |
| Layout | Keep the current layout (gear panel left, item list right, filter bar and selectors on top). No sidebar. | The addon has one view; a sidebar would add navigation that does not exist. |
| Code style | Match **this** repo (4-space indent, `stylua.toml`, `ns` modules, `--- ` doc comments), not Nrage's 2-space style. | Consistency with the surrounding code. |
| Accent | Alliance blue `#3FA7FF` as a single token (`Theme.colors.accent`). | Same as Nrage; keeps a future accent setting possible. |
| Behavior | No change to filters, lists, tooltips, alerts, sharing, commands or saved variables. | Visual-only change; the domain is out of scope. |

## 2. Design tokens (copy from Nrage `Theme.lua`)

| Token | Value | Use |
|---|---|---|
| `bg` | `#121010` | window ground |
| `panel` | `#191614` | cards (gear panel, item rows group, notice) |
| `side` | `#0D0C0B` | header bar |
| `control` | `#231F1C` | buttons, dropdowns |
| `input` | `#0B0A09` | search box |
| `border` | white @ 0.08 | every 1px border and divider |
| `text` / `dim` / `muted` | `#F3EFEA` @ 1 / 0.68 / 0.50 | primary, secondary, captions |
| `accent` / `onAccent` | `#3FA7FF` / `#0A0C10` | primary buttons, progress bar, focus, selected |
| `success` / `warning` / `danger` | `#5BD69A` / `#F5B84C` / `#F07272` | owned / partial / missing states |
| hover / selected / stripe | white 0.06 / white 0.07 / black 0.14 | row hover, selection, alternate rows |

Item quality colors stay as the game defines them (item names keep their quality color).

**Typography:** Fira Sans Regular, Medium and SemiBold, no outline. Sizes: 15 semibold window title, 13 regular body and controls, 12 regular secondary lines and buttons, 11 semibold uppercase section labels in `muted`.

**Metrics:** header 52 px; content padding 20 px; card = `panel` fill + 1px `border`, square corners, 14–18 px padding; buttons 28 px (secondary) / 30 px (primary); inputs and dropdowns 28–32 px.

## 3. Files to add

| File | Content |
|---|---|
| `ForeverBiS/UI/Theme.lua` | `ns.Theme`: `Hex`, `colors`, `Color(name, alpha)`, `StatusColor(word)`, font objects created lazily via `CreateFont` (`Theme.Font(size, weight)`), metrics table. Port from Nrage `Theme.lua`, trimmed to what this addon uses. |
| `ForeverBiS/UI/Pixel.lua` | `ns.Pixel`: `Snap`, `Size`, `Border(frame, color)` with `SetColor`/`Resize`. Port from Nrage `Pixel.lua` (guard `GetPhysicalScreenSize` with `pcall`). |
| `ForeverBiS/UI/Skin.lua` | Small helpers that apply the theme to raw frames: `Skin.fill(frame, token)`, `Skin.card(frame)`, `Skin.button(button, "secondary"|"primary"|"ghost")` (fill, border, hover wash, text color, disabled state), `Skin.editBox(box)`, `Skin.text(fontString, size, weight, token)`, `Skin.sectionLabel(fontString)`, `Skin.icon(texture, name, token)`. |
| `ForeverBiS/UI/Dropdown.lua` | A themed dropdown (button + dark popover list built from `CreateFrame` and solid textures) replacing `UIDropDownMenuTemplate` for class, build, phase and dungeon. Closes on Escape, on outside click and when the window hides. Port the visual style of Nrage `Controls.lua` Dropdown and `Shell.lua` Popup/Menu, simplified. |
| `ForeverBiS/Media/Fonts/` | `FiraSans-Regular.ttf`, `FiraSans-Medium.ttf`, `FiraSans-SemiBold.ttf`, `OFL.txt` (copy from Nrage). |
| `ForeverBiS/Media/Icons/` | Only the icons used: `close`, `search`, `chevron`, `check`, `cross`, `dash`, `alert`, `list`, `gear` (copy the `.tga` files from Nrage). |

Add the new Lua files to `ForeverBiS.toc` **before** the UI modules that use them (`UI\Theme.lua`, `UI\Pixel.lua`, `UI\Skin.lua`, `UI\Dropdown.lua`). Update `tools/package.sh` if it lists files or folders explicitly, so `Media/` ships.

## 4. Per-module changes

1. **`UI/MainFrame.lua`** — drop the `BackdropTemplate` dialog art. `bg` fill + 1px `border`. A 52 px header strip in `side` with the logo (`ForeverBiSIcon.tga`, 30 px), title (15 semibold), a version badge (from the TOC `Version` via `C_AddOns.GetAddOnMetadata` / `GetAddOnMetadata` behind `pcall`) and a 32 px flat close button using the `close` icon (hover = `danger` tint). The header is the drag area. Resize grip bars use `muted` instead of gold. Keep `MIN_WIDTH`, `userSized`, `toggle/open/refresh/settle` semantics unchanged.
2. **`UI/Selectors.lua`** — class, build and phase use the themed `Dropdown`. Labels become 11 px uppercase section labels. Menu entries, checked state and callbacks keep the same behavior ("Auto (%s)" for phase included).
3. **`UI/FilterBar.lua`** — search box with `Skin.editBox` (`input` fill, border turns `accent` on focus, `search` icon on the left, hint in `muted`). Filter toggle buttons become secondary buttons; an active filter shows the `selected` wash plus an `accent` text/underline. Dungeon filter uses `Dropdown`. Clear-search button becomes a ghost icon button.
4. **`UI/ItemList.lua`** — scroll frame keeps working but the default `UIPanelScrollFrameTemplate` bar is restyled (thin `border`-colored track, `muted` thumb, hover `dim`) or replaced with a minimal custom thumb. Group headers: 11 px uppercase section labels with a 1px divider; collapse button uses the `chevron` icon rotated. "Clear all" becomes a secondary button. Empty state: centered icon, one-line title and a `muted` hint inside a card. Count text in `dim`.
5. **`UI/ItemRows.lua`** — each row: 1px `border` divider between rows, alternate `stripe`, hover wash. Icon with a 1px quality-colored border, name in quality color, rank/source/detail/effect lines in `dim`/`muted` at 12 px. Faction label as a small chip (status color @ 0.14 ground). Owned / equipped markers use the `check` icon in `success`; missing uses `dash` in `muted`.
6. **`UI/ItemWidgets.lua`** — bag count and similar overlays use Fira Sans 11 with a soft 1px shadow (they sit over item art).
7. **`UI/PaperDoll.lua`** — the gear panel becomes a card (`panel` + border) instead of `BackdropTemplate`. Name (15 semibold), class and level in `dim`. Slot buttons: dark `input` ground with a 1px border, quality-colored border when filled, `accent` border on hover/selected. "Equipped only" becomes a secondary toggle button with the selected wash when on. The player model stays.
8. **`UI/Progress.lua`** — a 6 px bar: `control` track, `accent` fill (`success` when complete), text in `dim` 12 px.
9. **`UI/Help.lua`** — help button as a ghost icon button; the help popover in the theme (`panel`, border, 13 px body, section labels).
10. **`UI/DungeonNotice.lua`** — the notice becomes a themed card/banner: `panel` fill, 1px border, a 3 px `accent` bar on the left, `alert` or `list` icon, title 13 semibold and body in `dim`. Keep its click, timing and dismissal behavior.
11. **`UI/Minimap.lua`** — keep the logo and the round minimap ring (minimap convention) and the drag behavior. If it has a custom menu or tooltip, restyle the menu to the dark popover.

Every user-visible string keeps going through `L[...]`; add `esES` (and any other existing locale) entries for new strings such as the version badge text, if any.

## 5. Tests and checks

- Extend `tests/stubs/wow_api.lua` so frames and textures accept the new calls: `SetColorTexture`, `SetVertexColor`, `SetTexCoord`, `SetRotation`, `SetFontObject`, `SetFont`, `SetShadowOffset`, `SetShadowColor`, `CreateFont` (global returning a font object with `SetFont`, `SetTextColor`, `SetShadow*`), `GetPhysicalScreenSize`, `GetEffectiveScale`, `SetHighlightTexture` etc. — whatever the new code calls.
- Unit-test the pure helpers: `Theme.Hex`, `Theme.Color` (alpha override), `Pixel.Snap`, `Pixel.Size` fallbacks, `Dropdown` selection/close logic, `Skin.button` state changes (enabled/disabled/active).
- `tests/interaction_spec.lua` and `tests/addon_spec.lua` must keep passing: the UI must still build, open, filter, select class/build/phase/dungeon and render rows through the stubs. Update them only where a template-specific call was asserted (e.g. `UIDropDownMenu_*`).
- Run with the LuaJIT tooling (`LUA_INIT` unset): `~/.luarocks/bin/busted~`, `~/.luarocks/bin/luacheck~ .`, `stylua --check .`, `tools/check_coverage.sh 80`. Never pipe a test run into a commit.

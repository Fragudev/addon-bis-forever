# Data schema v2 (superseded)

This schema is superseded by [data-schema-v3.md](data-schema-v3.md). Schema 2 was a single generated file,
`ForeverBiS/ForeverBiS_Data.lua`, with one source (ForeverChanges). Schema 3 keeps its `lists` shape (per route, per
phase, with `title` and `slots`) and its item and source fields, and adds one file per source plus the source API.
